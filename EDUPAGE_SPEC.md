# EduPage в работе школы: наблюдения и пробелы «Атласа»

21.10.2026 рабочий EduPage школы осмотрен под ролью администратора, 22.10.2026 —
под учителем, учеником (служебная запись класса) и родителем, только для
чтения. Ничего не сохранялось и не отправлялось: формы открывались и
закрывались через «Отменить» или «Закрыть». Файл описывает поведение функций,
а не код, дизайн или тексты EduPage. Имена людей и сведения об учениках сюда не
переносятся. Статусы «Атласа» сверены с кодом и [EDUPAGE_ROADMAP.md](EDUPAGE_ROADMAP.md).

Не проверено: облачный редактор расписаний, форма заявления родителя,
отправка сообщения от ученика, платёжные и библиотечные модули в работе (у
школы они выключены).

## Масштаб школы

| Показатель | Значение |
|---|---|
| Ученики | 1135–1241 (по разным экранам), 55 классов по ~22 ученика |
| Учителя и сотрудники | 168 |
| Вход в систему | около 370 пользователей за обычный день |
| Оценки | ~96 тыс. за первые два месяца года; 1,5–3 тыс. в учебный день, пик 6,6 тыс. |
| Записи журнала | ~19 тыс. уроков с записью за два месяца |

Эти цифры стоит взять в [PERFORMANCE.md](PERFORMANCE.md) как ориентир для
нагрузочной приёмки: пиковая запись оценок, а не только число аккаунтов.

в «Атласе» уже есть, поэтому их доработка здесь не приоритетна.

## Подробности по модулям

### Классный журнал (администрация)
- Администратор не вносит данные, только настраивает и контролирует.
- Для каждого класса показаны дата последней записи, дата, с которой не
  заполнен учебный план, и с какой даты посещаемость ждёт подтверждения
  классного руководителя. Есть предпросмотр, печать и диаграмма.
  Сделано: дата последней записи и «не заполнено с» в сводке по классам
  ([JOURNAL_COVERAGE.md](JOURNAL_COVERAGE.md)); число дней без подтверждения
  посещаемости и напоминание классному руководителю
  ([ATTENDANCE_GRID.md](ATTENDANCE_GRID.md)); печати и диаграммы в сводке нет.
- Отдельное предупреждение: учителя, не связанные с расписанием.
  Сделано: администратор видит уроки, у учителя которых нет учётной записи
  (учитель считается не связанным, пока к нему не привязана учётная запись).
- Настройки:
  - запрет записей на будущее;
  - запрет ручного изменения уроков;
  - напоминание о пропущенной записи через N дней с уведомлением учителей
    (сделано: учебные дни, час и недельная сводка, по умолчанию выключено);
  - даты начала года, второго полугодия, концов полугодий;
  - отдельные даты блокировки журнала, посещаемости и записок об отсутствии;
  - нумерация недель.
- Дневной вид класса: по каждому уроку тема, домашнее задание со ссылкой и
  сроком, счётчик посещаемости. Межклассные группы видны в журнале каждого
  класса.

### Посещаемость учеников
- Сетка «день × урок» по ученику с итогами: всего, по уважительной причине,
  без уважительной, опоздания.
- Опоздание засчитывается как доля урока по минутам (по умолчанию от 5 минут).
- Выбор нескольких уроков (Ctrl, Shift, вся строка или столбец), затем
  контекстное меню: присутствовал, отсутствовал, опоздал, ушёл раньше, тип
  отсутствия, история записей.
- Коды отсутствия редактируются школой. Есть код «представляет школу»
  (олимпиада, соревнование).
- Записка об отсутствии от сотрудника: тип, причина, период дат, уроки с–по,
  только для одного предмета, массовая записка на несколько учеников.
- Журнал прихода и ухода ученика, «перерыв на обед до», возмещение проезда.

### Оценки
- Шкала оценок задаётся школой: символ, вес для среднего балла (A+ = 4,00 …
  F = 0,00), описание.
- Деление года: полугодия, триместры, четверти, модули, весь год, с вариантами
  пересдач. Для каждого периода:
  - показывать ли промежуточные оценки семье;
  - запрет правки;
  - правка итоговых оценок.
- Годовая оценка: из итогов периодов, среднее периодов, среднее всех оценок
  или без годовой.
- Задания:
  - общие категории администратора;
  - заготовки заданий для многих классов;
  - разрешённые типы: оценки, баллы, проценты;
  - проверки ввода: только числа, целые, в пределах шкалы.
- Автоуведомления ученикам по правилам (простые и расширенные).
- Права: свободный режим или только свои курсы плюс выданные явно.
- Цвет оценки по интервалам; словесная оценка из стандартных фраз; оценка
  поведения по предметам в выбранных категориях.
- Родитель подписывает оценки только из своего аккаунта; семье можно
  показывать вычисленное среднее.
- Итоговая оценка вычисляется по интервалам среднего или по набору правил.
  Значение «+» и «−» настраивается.
- Также есть импорт оценок, сравнительная статистика, статистика по классам и
  учителям, история.

### Табели и дипломы
- Табели: обзор всех классов по периоду и пошаговый процесс:
  1. Предметы в табеле.
  2. Итоговые оценки.
  3. Словесная оценка.
  4. Генерация PDF.
  5. Публикация оценок и PDF семье.
  6. Печать.
- Дипломы: шаблоны по языку, категории (конкурсы, искусство, спорт, учёба,
  экология, свой заголовок), ориентации и фону; вкладки «Ученики» и «История».

### Официальные письма и воспитательные меры
- Вкладки: Обзор, Заметки, Официальные письма, Табло, История. Фильтры по
  классу или параллели, периоду, состоянию, типу, поиску; группировка.
- Типы (список настраивается):
  - быстрые положительные и отрицательные отметки поведения на уроке;
  - меры учителя и классного руководителя: замечание, похвала,
    предупреждение об успеваемости, снижение оценки за поведение;
  - меры директора: похвала, замечание, условное и безусловное исключение;
  - письма-решения: индивидуальный учебный план, освобождение от предмета,
    повтор оценивания, перевод, перерыв или смена формы обучения.
- Состояния: «не одобрено» → «одобрено» (видимое или скрытое) либо
  «отклонено». В форме:
  - причина с готовыми текстами;
  - печать в табель;
  - период и предмет;
  - несколько учеников сразу;
  - «не показывать ученику и родителю».
- «Табло» — рейтинг учеников по числу отметок с пьедесталом; активно
  используется в 1–3 классах.
- «Комиссионные экзамены»: список, генерация решений, печать протоколов,
  рассылка результатов.

### Замены и расписания
- Замены на день:
  - отсутствующие учителя, классы и кабинеты;
  - события дня: дополнительные уроки, консультации, прочее;
  - таблица: класс, предмет, тип замены, кто заменяет, кабинет, примечание;
  - рассылка учителям, печать, экспорт, публикация.
- Подбор замещающего ранжируется по весам критериев: свободен, учит класс,
  классный руководитель, тот же предмет, объединение классов, дежурство,
  постоянный заместитель, лимиты уроков в день.
- Публикация отдельно для учеников и для учителей: формат имён, показ
  отсутствующих, причины и типы замен только учителям, прошлые замены.
- «День в расписании»: для каждой даты задаются файл расписания, день недели,
  буква недели и семестр.
- Расписания:
  - файлы со счётчиком версий и датами действия;
  - состояния «хранимый», «черновик», «официальный», для каждого свои права
    просмотра у учителя, ученика и гостя;
  - публикация ФИО гостям выключена;
  - дерево версий с ветками и сводкой изменений;
  - автоматические копии.

### Сотрудники, реестр, отчёты

## Учитель, ученик и родитель

### Учитель
- Главная: свои уроки на сегодня с отсчётом до звонка, сообщения от учеников,
  школьные объявления, напоминания администрации «заполните посещаемость».
- Журнал дня:
  - тема выбирается из плана курса, домашнее задание — «→ следующий урок»;
  - счётчик посещаемости открывает карточки учеников с фото, по умолчанию все
    присутствуют (в «Атласе» с 31.10.2026 карточки с инициалами, см.
    `LESSON_ATTENDANCE.md`);
  - в меню ученика: оценки, записки, «Уведомление / письмо»;
  - «Отсутствующих нет» подтверждает урок;
  - пустой номер урока — «Добавить урок»;
  - «Добавить из расписания с предыдущих дней»;
  - красные дни календаря — незаполненные;
  - «Заметки недели».
- Оценки:
  - выбор курса (класс и предмет, сборные курсы на много классов);
  - таблица заданий с цветом категории, средним, стандартным отклонением,
    вычисленной буквенной и итоговой оценкой;
  - «Новая заметка» и «Воспитательная мера» прямо в таблице.
- Новое задание:
  - название, краткое имя;
  - категория: школьные «формативное», «суммативное за раздел», «суммативное
    за семестр» или одно задание сразу в нескольких категориях;
  - тип, вес (0x дополнительные баллы, 0,25x, 0,5x, 1x, 2x, 3x, свой),
    максимум баллов, дата;
  - дополнительно: группа, сколько оценок на ученика, цвета, семестр;
  - учёт нескольких оценок: каждая отдельно, среднее с весом, лучшая,
    последняя, сумма со средним, сумма с добавлением максимума;
  - проверки ввода.
- Материалы курса — меню «+»:
  - тест или презентация с помощью ИИ, тест, домашнее задание, презентация,
    запланированный экзамен, проект;
  - вопросы: выбор, ввод или выбор в тексте, сортировка, точки на карте,
    категории, выбор категории, пары, плитки, открытый вопрос;
  - слайды нескольких макетов;
  - текст, картинка, видео, файлы.
- Единая кнопка действий: сообщение, доска, фото, работы учеников, оценка,
  заметка, мера, записка, тема урока и посещаемость, тесты и задания.
- Сообщение:
  - получатели — вся школа, учителя, классные руководители, сотрудники,
    только родители, только ученики, ученики и родители, «мои курсы», свои
    группы;
  - файлы, ИИ-проверка текста.

### Ученик
- Главная: расписание дня с отсчётом, объявления с вложениями (итоговый
  проект с вариантами и критериями), ближайшие задания с запуском онлайн-теста.
- Оценки:
  - «Поведение» отдельной строкой;
  - вкладки «Заметки» (группировка по предмету, учителю, дате, типу),
    «Самооценка», «Компетенции», «Оценки на графике»;
  - «Просмотрено» подписывает новые оценки.
- Учебный план: свои курсы с учителями и кружки. Посещаемость: своя сетка и
  записки.
- В школе используется служебная запись «1Присутствуют Все» в каждом классе
  как строка «все присутствуют». Её иногда ошибочно отмечают отсутствующей.
  В «Атласе» нужна нормальная кнопка вместо фиктивного ученика (сделано
  31.10.2026: «Отсутствующих нет», `LESSON_ATTENDANCE.md`).

### Родитель
- Меню аккаунта со списком детей (класс, год); выбор ребёнка переключает весь
  портал.
- Главная:
  - расписание ребёнка;
  - каждая новая оценка с комментарием учителя («не писал тест?»);
  - объявления для родителей класса;
  - задания нескольких детей вместе.
- Оценки: те же вкладки, что у ученика, плюс «Подписать оценки». График
  накопленных баллов по каждому предмету: блоки заданий «9 / 10 = 90%»,
  зоны оценок от красной до зелёной, отметка текущего уровня, значки заметок.
- Посещаемость: сетка ребёнка, опоздания как доли урока, приход и уход.
  Электронную записку можно подать, только если её разрешил классный
  руководитель; иначе — «свяжитесь с классным руководителем».
- Заявления: «Мои заявления» с состояниями и связью с записками.

### Ошибка часового пояса в EduPage
В настройках школы указан `Asia/Almaty` (UTC+5), но конец дня сдачи
задания сервер считает по своему центральноевропейскому времени. Например,
срок «21.10» хранится как `2026-10-22 02:59:59`, а ученик видит «до 22.10.
02:59». После перехода Европы на зимнее время будет 03:59. Отметки
синхронизации тоже идут по CEST. Исправить это может только поддержка
EduPage; менять часовой пояс школы не нужно. В «Атласе» сроки считаются по
`Asia/Qyzylorda`.
